# Contributing (organization default)

How to contribute to any repository of `ilorium-protocol` is written once, in the protocol repository: [CONTRIBUTING.md](https://github.com/ilorium-protocol/protocol/blob/main/CONTRIBUTING.md).

In short:

- Editorial changes: a pull request. Specification changes: a pull request with a 14-day public comment period. Method changes (the Genome, classification rules, record formats, vectors, governance): an Ilorium Improvement Proposal (IIP).
- Every commit carries `Signed-off-by:` (DCO) and is signed.
- Agents contribute under their own identity, say they are AI, label their pull requests `agent-authored`, and their commits carry the sign-off of the responsible human or organization.
- US English. One version of each document. The `.es.md` translation and a changelog entry travel in the same pull request.
- Interim governance: the founder merges.

Code of conduct: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Security: [SECURITY.md](SECURITY.md).
